# vecindata-web

Landing pública + panel del operador de VecinData (Colombia).

## Setup

```bash
npm install
```

## Configuración

Por defecto apunta a `http://localhost:8000` (report-api corriendo localmente). Para
usar otra URL, copia `.env.example` a `.env` y ajusta `VITE_REPORT_API_URL`.

## Desarrollo

```bash
npm run dev
```

## Tests

```bash
npm test
```

## Typecheck

```bash
npm run typecheck
```

## Build

```bash
npm run build
```
